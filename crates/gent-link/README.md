# Gent

Gent connects Codex and Claude Code chats across providers and machines. The `gent-link` package installs the `gent` CLI, which includes the local daemon and desktop companion for Linux and macOS.

```sh
cargo install --locked gent-link
gent setup
```

Use Rust 1.98 or later and your platform’s native build tools. On macOS, install the Xcode command-line tools for the desktop companion. After setup, the built-in updater follows the cluster’s selected Stable or Beta Git release. Run `gent version` to see the installed revision. [Installation guide](https://github.com/sam0x17/gent/blob/stable/docs/installation.md) · [Updates and rollback](https://github.com/sam0x17/gent/blob/stable/docs/updates.md)
