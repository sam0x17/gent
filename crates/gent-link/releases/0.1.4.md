Gent Babysitter can resume a Codex goal after queued work finishes, including a queued turn that received and answered a Gent relay request. If you start a separate turn to investigate the failure and that turn also stalls, Babysitter can continue your investigation while the goal stays blocked.

Ordinary chat recovery also recognizes a user turn with follow-up instructions before or between confirmed Gent messages. That turn can receive one automatic `please continue`. A Codex handoff that received Gent notifications can also get one retry once Babysitter verifies each delivery. Accepted requests for user input stay paused.

If a retry also fails, a command that finishes late from its parent turn no longer prevents the next eligible retry.
