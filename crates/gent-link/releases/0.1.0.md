This is Gent’s first crates.io release. The `gent` CLI and desktop companion connect managed Codex and Claude Code chats across enrolled machines. Free includes Babysitter. It resumes eligible goals after provider failures in managed Codex and Claude Code chats. Ordinary Codex recovery is off by default. Enable it in Settings or with `gent config ordinary-chat-recovery enable`.

Install with `cargo install --locked gent-link`, then run `gent setup`. To pause routine updates on this node, run `gent update disable`.
