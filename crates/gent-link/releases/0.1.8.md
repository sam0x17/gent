Gent Desktop can group parallel work into status lanes. Mark a pair of event feeds to show them side by side. On wide boards, a long second feed can continue into a third column. On narrow boards, the feeds stack in reading order.

A chat can attach a private, scriptless HTML view to a dashboard revision. Desktop checks access to the file before displaying it and shows the native widgets when the attachment is unavailable. Older desktops continue to show those widgets and read lanes and paired feeds as ordinary event lists.
