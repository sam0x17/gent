Babysitter can continue a Codex chat after a provider failure when Codex updated its tool list as you started the turn. If you received Gent messages during that turn, Babysitter checks their native delivery receipts. This also covers a message Gent claimed in the same second you submitted the instruction, when Codex recorded its delivery in a later second. A qualifying turn with both user and Gent input can receive one automatic `please continue`.
