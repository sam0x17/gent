Babysitter can retry a Codex chat or blocked goal after HTTP 503 “Server is draining” or the temporary high-demand message. If another agent opened a chat turn and more handoffs arrived while it ran, Babysitter can retry that turn once after a provider failure.

A loaded Codex chat can receive its next queued Gent message after a provider failure, including when an older Gent adapter is still attached. Gent checks that Codex can accept input and that its native queue is empty before delivering the message.

The empty Dashboard labels its graph **Example dashboard** and its data **Sample test results**. It includes prompts you can give a registered chat to build a dashboard like it and keep it updated. The example also appears when you hide all your dashboards.
